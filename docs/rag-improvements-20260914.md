# RAG 本地改进与验证（2026-09-14）

本次代码把一般心理科普与对话行为分开：对话可以倾听、澄清和尊重选择；专业事实必须由本轮检索资料支持。没有合适证据时说明覆盖不足，不要求模型凭记忆补写心理机制、诊断标准或疗效。

## 实际变更

- 新增 40 张、22 个原始机构来源的一般信息卡，直接随应用读取，不需要调用付费模型或重新灌入 Qdrant。每张仍是 `clinicalStatus: pending`、`professionalReview: not_performed`；来源核对不等于专业人员审核。
- 新渠道只接受本地登记对象，且要求已核对原始来源、明确一般信息用途、可核对 HTTPS 机构链接、空 `guidance`。远程 Qdrant 的 pending 卡不能靠复制这些字段获得许可。原临床通道继续要求 `approved`；旧标记本身不证明存在真实专业签名。
- 检索请求仅含受控主题词和信息意图，例如“睡眠 / 定义 / 求助 / 证据”。短追问可以继承紧邻上一条用户的主题；当前明确主题优先。个人档案、模型个案假设、助手猜测和用户叙述不会拼进改写、向量或搜索请求。未知主题会产生覆盖不足，而不是把完整文本作为兜底外发。
- 本地来源卡先做关键词检索；未覆盖时保留原临床检索链。远程链共用快模式 2.5 秒、深模式 8 秒预算，同一查询只生成一个 embedding。Qdrant 成功返回空结果或 reranker 拒绝候选时保持空结果；深模式没有 reranker 时采用严格相似度下限。
- embedding 文件现在记录每张卡实际嵌入文本的 SHA-256。没有指纹或正文变化的旧向量不参与检索。远程候选若与同 ID 当前本地正文不同，也不能沿用旧文得分。
- Qdrant 与网络搜索响应再次本地检查机构域名、HTTPS 和非空来源内容，不能仅依赖发给服务商的过滤参数。
- 来源面板显示“本轮参考资料”，明确检索到不表示所有资料都被采用，也不表示每个生成判断经过核验。提示词要求每项专业主张得到具体资料支持，并把检索正文视作数据，避免将其当指令。

原危机/医疗优先路线、地区资源、同意与用户自主选择继续保留。第二组中文审查发现后，补充了跨词胸部疼痛、具有身体语境的呼吸困难，以及重要事项交代加近期终结感的确定性识别；另补明确拒绝建议的说法。此前的本地开发验证没有发布或改动生产环境。0.9.0 的线上状态以 Vercel 当前 Production 部署和发布检查结果为准。

| --- | ---: | ---: |

“指定来源命中”是精确匹配该用例指定的页面，不能解释成旧系统只有 5% 正确、或新系统 100% 正确。这些是 AI 撰写并用于改进检索词表的开发用例，不是盲测集或临床金标准。它们能防止已知工程问题复发，不能证明咨询疗效、回答安全性或超过某个基础模型。实际生成是否遵守证据边界仍需对照生成和独立人工评审。

另有单元与路由回归覆盖多轮指代、主题切换、识别信息不外发、未审核远程卡拒绝、伪造域名、缺失向量指纹、重复 embedding、总时限、无证据提示、危机优先级及来源面板真实措辞。

另写的 18 条中文问题首次仅 11 条通过，暴露了短追问、拒绝建议、咨询准备和确定性医疗/危机识别缺口。修复后 18 条通过，首次与修复后报告均保留在 `eval/rag-independent/`；这些题此后属于开发回归，不再称作盲测。详情见该目录的 README。

## 仍存在的限制

主题词表和关键词检索覆盖有限；陌生说法可能得不到检索结果。当前没有逐句自动蕴含验证，来源面板也不把“检索到”包装成逐句引用证明。40 张新卡未经过心理专业人员审核，适用范围仅为一般科普信息。旧向量默认失效后将走本地关键词，后续需要有意重新构建带指纹的向量；本轮没有调用收费 embedding。

## 真实接口补查

主任务在本地生产构建做了 7 次合成问题请求。发现知识问题仍被默认督导强制套入情绪分析，因此增加独立的信息问答生成分支，移除治疗取向、痛点猜测和强制追问。又补齐治愈率、百分比和是否有效等信息意图。复测的百分比问题能明确说明资料未提供数字，也不补写未检索到的原因。医疗模板改为不把词表中的症状史归给用户，并清楚要求急性危险症状立即医疗求助。

这些只是少量工程试聊，当前网站提供商不是新 Qwen 适配器；不证明所有回答都会遵守证据，也不是临床或延迟基准。记录中的深聊请求仍经历上游风险判别器超时后的后备流程。上述改动最后通过完整 `npm run verify`：770 项测试通过、1 项跳过，TypeScript、生产构建和 standalone smoke 通过；另 18 题回归和 54 题本地检索回归通过。
