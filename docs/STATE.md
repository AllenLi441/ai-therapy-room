## 4. 架构

```text
用户 → 词表底线(本地) → 判官(DeepSeek v4-flash 主判;Kimi 有余额时作备用)
     → 拦截策略 decideImplicitIntercept → 路由(危机 / 关切 / 温和询问 / 普通)
     → 回答(DeepSeek v4-flash 快速档 / v4-pro 深度档) + 知识检索(知识卡 + 向量 + 网页)
```

- **外部服务:** DeepSeek(回答 + 判官)、硅基流动(向量检索,以及作为备用判官的 Kimi)、Qdrant。
- **Kimi 还在用的地方**(Kimi 欠费时的降级行为待排查):深度档复核、个案概念化、危机回复、看图。
- **部署:** Vercel(境外),https://ai-therapy-room.vercel.app,版本 0.9.0。
- **目标方向:** 精简为以 DeepSeek 为主的单一供应商;安全逻辑收拢成"安全内核"并接入自动回归门槛;加入青少年模式。
